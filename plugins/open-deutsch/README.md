# Open Deutsch plugin workspace

This directory contains the versioned Codex plugin payload, two bounded teaching/research skills, and the local MCP declaration. The `bin/open-deutsch-mcp.cjs` helper resolves the built workspace server or an installed sibling server, requires an explicit or unambiguous private bootstrap pointer, and keeps the packaged curriculum snapshot read-only and separate from learner data. The local MCP contract exposes eight bounded read/write tools. Real host activation remains behind the confirmation-gated plugin verification workflow.

The development manifest names the stable `open-deutsch-mcp` helper command. The packaged helper and its installed path are supplied by the AppImage/plugin package rather than a private checkout path. Listening and speaking writes accept structured outcomes or summaries only; exact Codex Voice session creation is unavailable in the current host, with no clipboard or generic-launch substitute.
