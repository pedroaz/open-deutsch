# Shared test support

Reusable deterministic clocks, identifier factories, disposable data-root helpers, and process fixtures live here. `vitest-disposable-data.ts` automatically gives every sequential Vitest case a unique restrictive data root, bootstrap pointer, and ambient process environment. Concurrent Vitest declarations are forbidden because ambient environment mutation is process-global, and the infrastructure test enforces that policy. `node-disposable-data.mjs` establishes the same isolation for every Node test-run process before test modules load. Child processes inherit those isolated variables; tests never resolve learner configuration. The harness ignores `TMPDIR`/`TEMP`/`TMP`, selects a fixed canonical Linux temporary parent outside configured learner roots, and fails closed if none is safe.
